
# Формат исходных данных

Все файлы представлены в формате CSV.

## contracts.csv — договоры

- contract_id — номер договора.
- contractor — подрядчик.
- amount — сумма договора в рублях.
- signed_at — дата подписания.

## works.csv — работы

- work_id — номер работы.
- contract_id — номер договора.
- title — название работы.
- price — стоимость работы.
- status — planned, done или cancelled.
- completed_at — дата приёмки.
- cancelled_at — дата отмены.

## payments.csv — платежи

- payment_id — номер платежа.
- contract_id — номер договора.
- work_id — номер работы, если платёж привязан к конкретной работе.
- purpose — назначение платежа.
- amount — сумма платежа.
- status — paid, queued или refunded.
- created_at — дата создания платежа.
- paid_at — дата фактической оплаты.
- refunded_at — дата возврата денег.

Даты имеют формат YYYY-MM-DD.
Денежные значения указаны в рублях с точностью до копейки.
Пустое work_id означает платёж по договору без привязки к конкретной работе.
