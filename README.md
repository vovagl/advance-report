
# Отчёт по авансам и оплатам договоров

## Описание

Программа формирует отчёт по выплатам подрядчикам на выбранную дату.

Отчёт содержит:
- стоимость каждой работы;
- фактически выплаченную сумму;
- остаток к оплате;
- итоги по каждому договору;
- предупреждения о расхождениях.

## Требования

- Python 3.9 или новее.
- Сторонние библиотеки не требуются.

## Структура проекта

## Запуск

Откройте терминал в корневой папке проекта.

Запустите:

```bash
python main.py --date 2026-11-10
```

Дата передаётся в формате YYYY-MM-DD.

## Результаты

После запуска в папке output появятся:

- work_report.csv — отчёт по работам;
- contract_report.csv — итоги по договорам.

CSV-файлы сохраняются в UTF-8 с BOM и разделителем `;`, чтобы их было удобно открывать в Excel.

## Автоматические тесты

Запуск тестов:

```bash
python -m unittest discover -s tests -v
```

Тесты проверяют:
- пропорциональное распределение платежей;
- округление до копеек;
- учёт даты платежа;
- возвраты;
- платежи в очереди;
- итоговые суммы отчёта.

## Денежные расчёты

Для денежных значений используется Decimal.
Распределение выполняется в целых копейках.
Тип float не используется.
